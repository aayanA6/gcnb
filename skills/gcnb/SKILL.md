---
name: gcnb
description: Start, stop, or check the gcnb chat server (an iMessage-style UI for Claude Code agents). Use for "/gcnb", "/gcnb stop", "/gcnb status".
---

Run the bundled launcher with the Bash tool, passing the argument through as-is (default to "up" with none):

- `/gcnb` or `/gcnb up` -> `gcnb up`
- `/gcnb stop` -> `gcnb stop`
- `/gcnb status` -> `gcnb status`

Print whatever the command outputs. Don't add extra narration.
